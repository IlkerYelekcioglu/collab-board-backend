## 🛠️ Kullanılan Teknolojiler

**Backend:**
*   Java 17 & Spring Boot 3
*   Spring Security (JWT Authentication)
*   Spring WebSocket (STOMP)
*   Spring Data JPA
*   PostgreSQL (İlişkisel Veritabanı)
*   Redis (Çevrimiçi kullanıcı durumu için)

**Frontend:**
*   React 18 (Vite ile)
*   Axios (API İstekleri)
*   @stomp/stompjs (WebSocket Bağlantısı)
*   @dnd-kit (Sürükle-Bırak - *opsiyonel*: eğer hala kullanıyorsan)

**DevOps / Altyapı:**
*   Docker & Docker Compose
*   Nginx (Frontend sunumu ve API yönlendirmesi için)
